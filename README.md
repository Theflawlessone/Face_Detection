# Face_Detection

This is a Regression model trained to recognize faces

# Project Setup
- **Notebooks** is where the multiple iterations of our ipynb files are. This holds the code where we cleaned the data and ran the model.
- **pickle_files** is where the data is stored, that be training data, test data, and the like. The files are in pkl format and are imported into our code via the pickle Python library.
- **index.html** and its accompanying folders 'assets' and 'vendor' is the frontend of the project.
