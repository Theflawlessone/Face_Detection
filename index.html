Baseline CNN

This baseline convolutional neural network consists of sequential convolution, ReLU, and pooling layers, followed by dense layers for prediction. It establishes a benchmark for age and gender prediction on UTKFace.

While simple, this architecture provides insight into initial performance metrics and helps identify preprocessing or architectural improvements needed for more advanced models.

×

CNN + Dropout

This improved CNN includes dropout layers to prevent overfitting and additional convolutional blocks for better feature extraction. Validation performance is more robust than the baseline.

It also serves as a precursor for multi-task learning, demonstrating how regularization and deeper architectures can enhance prediction accuracy.

×

Multi-task Age & Gender

This final model predicts both age and gender simultaneously using shared convolutional layers and two separate output heads. The shared representation improves feature learning efficiency.

It outperforms previous models by capturing more complex facial attributes and allows simultaneous evaluation for both tasks with high accuracy and lower MAE for age prediction.
